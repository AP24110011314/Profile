# Aman Maddheshiya - Developer Portfolio

![Portfolio Preview](Photo.jpg)

Welcome to the source code of my personal developer portfolio! This repository contains a fully responsive, dark-themed website designed to showcase my skills, projects, educational background, and competitive programming achievements.

🌍 **Live Website:** [https://ap24110011314.github.io/](https://ap24110011314.github.io/)

## ✨ Features

- **Modern UI/UX:** A sleek "Neo-Brutalist" dark theme with ambient glowing gradients, CSS grid backgrounds, and a premium aesthetic.
- **Responsive Design:** Fully mobile-optimized layout that adapts seamlessly to desktop, tablet, and mobile screens.
- **Scroll Animations:** Built-in Intersection Observer logic for smooth reveal animations as you scroll down the page.
- **Interactive Certificate Viewer:** Custom-built image modal to view high-resolution certificates without leaving the page.
- **Dynamic Navigation:** Sticky navigation bar with active state highlighting and a responsive hamburger menu for mobile devices.

## 🗂 Sections Included

1. **Hero Section:** Introduction, key statistics, and a professional photo with animated rings.
2. **Experience & Education:** A visual timeline detailing academic journey and internships.
3. **Projects:** Highlighted full-stack and algorithmic projects with direct links to source code.
4. **Competitive Programming:** Visualized LeetCode progress bars and CodeChef badges.
5. **Technologies & Skills:** Categorized technical toolkit using emojis and flex-wrap tags.
6. **Achievements:** Notable scholarships, test scores, and recognitions.
7. **Certificates:** Gallery of professional and academic certificates.
8. **Contact:** Links to email, phone, LinkedIn, and GitHub.

## 🛠️ Technology Stack

- **HTML5:** Semantic structuring and accessibility.
- **CSS3:** Custom properties (variables), Flexbox, CSS Grid, media queries, and keyframe animations. No external UI frameworks were used.
- **Vanilla JavaScript:** DOM manipulation, event listeners, modal handling, and scroll-spy logic.

## 🚀 Running Locally

To run this project locally, you don't need any complex build tools or servers.

1. Clone the repository:
   ```bash
   git clone https://github.com/AP24110011314/AP24110011314.github.io.git
   ```
2. Open the directory:
   ```bash
   cd AP24110011314.github.io
   ```
3. Open `index.html` in your favorite web browser.
   ```bash
   # On macOS
   open index.html
   ```
